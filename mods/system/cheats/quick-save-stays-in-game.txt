# name: Quick Save Never Return To Title
# enabled: no
# status: untested
# category: Speed & comfort
# replaces: Quick Save Never Return To Title
# about: After a quick save the game goes on instead of going back to the title screen.
# Overlay 2 (the quick save screen): when the save is done it writes a 1 to a flag (byte at base + 0xCC2) that
# state 2 of the same screen reads at 0x0216B194 to go to state 3, which ends in the title screen. That
# store (strbeq r1, [r0, #0xCC2]) becomes a no-op, so the flag stays 0 and the screen carries on as after a normal save.
check 0216A1E8 03A01001
check 0216A1F4 05801BC0
patch 0216A1EC 05C01CC2 E1A00000
