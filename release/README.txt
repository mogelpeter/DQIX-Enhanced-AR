DQIX Enhanced AR - cheats for DQIX Enhanced
===========================================

What you need
  - Windows 10 or 11 (64-bit), and an internet connection for the first build.
  - DQIX Enhanced (github.com/sackchief/dqix-enhanced), installed and built once
    with your own Dragon Quest IX ROM. Its installer does that.

How to install
  1. Right-click the downloaded zip (release-<version>.zip), choose "Extract All...", then Extract.
  2. Open the new folder and double-click "Install.bat".
     (If Windows says "Windows protected your PC": More info, then Run anyway.)
  3. The installer asks where your DQIX Enhanced folder is (the one with BUILD.bat in it).
     It usually finds it by itself and only asks you to confirm.
  4. Wait. It puts the files in and builds the cheats into the game. The first time
     this takes a few minutes; black windows with scrolling text are normal.
  5. Start the game as always. In its menu bar: Cheats > Cheats...
     Nothing is switched on until you switch it on.

Close the game before installing. Updating: run the new version's installer the same way;
your choices in the game and your save are kept.

Something went wrong?  A log of the installer is in %TEMP%\dqix-cheats-install.log.
The build's own log is in <your DQIX Enhanced folder>\mods\system\bin\build.log.
More help: mods\README.txt, or github.com/mogelpeter/DQIX-Enhanced-AR
